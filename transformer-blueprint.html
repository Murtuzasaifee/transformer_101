02 · Reading the input

The Encoder stack

Six identical layers, each one refining the sentence's meaning a little more — like passing a draft through six editors in a row.

03 · Writing the output

The Decoder stack

Also six layers — but each one does three things instead of two: look at its own earlier words, look back at the encoder's memory, then think it over.

04 · What the model is allowed to see

Two kinds of masking

Masking is just a rule that says "block attention to this position." There are two independent rules, combined for the decoder.

05 · The core mechanism

Scaled dot-product attention

For every word (the query), attention decides how much to "listen to" every other word (the key), then blends their content (the value) accordingly. Click a word to see its attention distribution.

Analogy Each word asks a question ("query"), every word offers a label describing what it holds ("key"), and softmax decides how much to listen to each one before blending their actual content ("value").
Multi-Headed Attention h = 8 heads

Instead of running attention once with the full 512-number vector, the model splits each word into 8 smaller "heads" of 64 numbers each, runs attention separately on every head, then stitches the results back together. Each head can specialize — one might track grammar, another might track topic.

inputquery/key/value — shape [1, 3, 512]
split→[1, 8, 3, 64] — 8 independent heads
attend→each head runs attention independently
combine→[1, 3, 512] — heads concatenated + final linear layer
06 · Private thinking time

The position-wise feed-forward network

After words finish talking to each other via attention, each word goes alone into a "private room" and is processed by the exact same small neural net — independently, with no cross-talk.

class PositionwiseFeedForward(nn.Module):
    def forward(self, x):
        return self.w_2(self.dropout(self.w_1(x).relu()))
inputx — shape [1, 3, 512]
w_1→expand to [1, 3, 2048], then ReLU
w_2→compress back to [1, 3, 512]
Analogy Attention is a group discussion where words share information. The feed-forward step is each word then going off alone to privately think over what it just heard — using the same fixed thinking process every word uses.
Does it have backpropagation?

Yes — but not on its own. Backprop is one single process that runs through the entire model at once. Toggle the direction below to see the same steps run in reverse.

x→ w_1→ relu→ dropout→ w_2→ output

Numbers flow left to right: input → expand → non-linearity → compress → output.

07 · Turning words into numbers

Embeddings & positional encoding

Before any of the above can happen, raw words need to become numbers — and the model needs a way to know word order, since attention alone has no sense of position.

Embeddings

A lookup table: each word ID maps to a learned vector. Simple as a dictionary lookup.

input"cats" → id 17
lookup→[0.02, -0.5, ...] (512 numbers)
scale→× sqrt(512)
Positional Encoding

A fixed wave pattern (sine/cosine) is added on top, so the same word looks different depending on where it sits in the sentence.

"I"+ pattern for position 0
"love"+ pattern for position 1
"cats"+ pattern for position 2
Analogy Embeddings translate a word into "math language." Positional encoding stamps a timestamp on it, so the model knows "this word came first, this one second" — something attention itself doesn't track on its own.
08 · Putting it all together

make_model() — the recipe

One function builds every piece discussed above and wires them into a single EncoderDecoder, using default sizes from the original paper.

N = 6encoder layers, and 6 decoder layers
d_model512 — size of each word's vector
d_ff2048 — expanded size inside feed-forward
h = 8attention heads per layer

Every reused module (attention, feed-forward) is deep-copied before being handed to a new layer — otherwise multiple layers would accidentally share the exact same weights and update together, defeating the point of having separate layers. Finally, all weight matrices get Xavier-uniform initialization so training starts from a well-balanced set of random numbers.

Analogy Think of make_model() as a recipe card: it doesn't invent new ingredients, it just measures out 6 copies of each layer, assembles them in order, and hands you the finished, ready-to-train model.
